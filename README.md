# Piixel Price Check

A GitHub Pages-friendly Guild Wars 2 price-check tool made by Piixel.

## Included

- Searchable and filterable price-check directory
- Material, currency, crafted-gift, precursor, and legendary resource pages
- Trading Post buy/sell/direct-trade depth tables
- Methodology and API-tools documentation views
- Client-side CSV export from every resource page
- Responsive layout for desktop and mobile

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server. No build step or package installation is required.

The included values are a dated snapshot for the front-end demo. A production integration can replace the local resource data with responses from the official Guild Wars 2 Trading Post API.
